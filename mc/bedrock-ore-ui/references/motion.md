# 开关与滑杆的动作

查看[实验室数值页](gallery_numbers.png)上的滑块尺寸与轨道对齐。开关和复选框的端点外观可查[贴图总览](texture_catalog.png)。

## 开关

关闭时方块在左，露出灰轨和 O；开启时在右，露出绿轨和 I。两端与悬停态使用 `switches/` 内的开关贴图。切换时保持轨道和点击热区不动，只移动手柄。业务状态在输入被接受时更新一次，装饰动画随后收尾。初次打开直接回显当前状态。

网易实现可在真实 toggle 上叠一个默认隐藏的 image。随附的 [开关帧带](../assets/textures/ui/ore_style/switches/switch_transition_frames.png) 为 **450 × 16**，依次是 15 个 30 × 16 的逻辑帧。第 0 帧和第 14 帧分别与开关的关闭、开启贴图一致。令 `p` 为当前开度（0 到 1），取 `round(14 * p)`，将 `uv` 设为 `[30 * 帧号, 0]`。动画经过透明区时用同色行底遮住原生状态图，结束时隐藏装饰层，让引擎继续处理悬停和焦点。

测试模组全程采用约 140 ms 的减速过渡。中途反向从当前开度起步，按剩余距离缩短时间。静止时不再写 UV。

## 滑杆

滑杆将当前值放在标题行末，已走过的轨道显示为绿色。连续数值使用连续轨；少数固定档位才画清晰分隔线。以五档为例，网易模板的档位数设为 5，回调索引为 0 到 4，显示值可映射为 1、2、4、8、16。

### 横向阻尼

以原生输入命中和量化后的值为目标。输入回调当次更新配置、数值标签和关联的业务进度。另存一个归一化绘制位置，只供方形手柄和本滑杆的绿色轨道使用。手柄在按住、移动和松开时保持 16 × 16 的方形轮廓，命中区跟随原生控件。

可按实际帧间隔做指数跟随，示例用秒计时的 `shown = target + (shown - target) * exp(-dt / 0.065)`。反向时从屏幕上当前的位置继续，离散滑杆先选档再向该档位移动。停手和松开后继续收敛；到达阈值后准确落在目标并停止逐帧写控件。初次显示、恢复默认和返回分类时直接按当前设置定位。65 ms 是实验室的调校值。切换开关和按下分段按钮各有自己的反馈方式。

网易模板见 [JSON UI 接入](netease.md)。实机验收时先缓慢横拖，再快速拖动、突然反向、停住、松手，最后点选远端档位。观察数值、手柄和绿色末端三者。拖动中应能看到指针和手柄的短暂间距；停住后间距消失，端点对齐。通过一次点击只能检查落点。
