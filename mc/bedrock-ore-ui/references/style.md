# 色板与控件

表中尺寸使用逻辑像素。按钮可以 70 × 21 为起点，按目标 GUI 缩放统一换算。点击区域可以大于可见图形。

| 部位 | 默认颜色或画法 |
| --- | --- |
| 顶栏 | 面 `#E6E8EB`，底沿 `#B1B2B5`，深字；返回箭头占独立方形热区 |
| 一级导航 / 内容面 | `#313233` / `#48494A`；导航选中行与内容面同色 |
| 分组与行界 | 深线配下方 `#5A5B5C` 亮线，铺满内容栏；正文左右留约 10–12 单位 |
| 正文 / 说明 | 白 `#FFFFFF` / 浅灰 `#D0D1D4`；浅底用黑字。游戏内优先项目现有中文字体，说明可从标题字号的约 0.85–0.9 倍起调 |
| 外轮廓 / 滑轨 | `#1E1E1E` / `#8C8D90`；滑轨完成段用选中绿 |
| 作用域提示 | `#FFE866` 配深字；需要收起时提供有下划线的操作 |

| 凸起按钮 | 上亮边 | 面色 | 面下沿 | 底影 | 字色及用途 |
| --- | --- | --- | --- | --- | --- |
| 普通 | `#ECEDEE` | `#D0D1D4` | `#E3E3E5` | `#68696A` | 黑；次要操作、普通查看 |
| 主要 | `#76A967` | `#3C8527` | `#639D52` | `#1E4314` | 白；主要操作、启用或选中 |
| 信息 | `#6C97ED` | `#2E6BE5` | `#5889EA` | `#173673` | 白；打开帮助、说明或示例 |
| 危险 | `#DA7272` | `#CA3636` | `#D55E5E` | `#651B1B` | 白；清除、删除等破坏性操作 |

按钮从上到下采用 1 单位深轮廓、1 单位亮边、可拉伸面、1 单位面下沿、2 单位底影、1 单位轮廓。所有转角为直角。标签居于凸起的面上。悬停或键盘聚焦时给高对比轮廓，按下时面和字一起下沉、底影变薄。禁用时压低明暗差并屏蔽激活。持久选中态在指针离开后继续显示。

| 控件 | 画法与交互 |
| --- | --- |
| 开关 | 左关右开。关闭时灰轨、方滑块在左，露出的右段画 O；开启时绿轨、滑块在右，左段画 I。让整个轨道响应切换。 |
| 滑杆 | 黑框窄轨，已走段绿、剩余段灰，方形浅灰手柄略高于轨道。枚举/步进值按实际档位吸附，需要时画刻线；连续值用连续轨。显示值随输入立即更新。方形手柄与绿轨末端共用一个有阻尼的横向位置，停手后贴合目标，首尾档可达。 |
| 分段选择 | 短选项等宽、边框相接；未选用灰底黑字，选中用绿色按下贴图，面顶和白字一起下沉，厚底影收起，下沿露出居中短白线。移开指针、操作别的控件和切换分类再回来都保持这一档。空间不足时换行或换为选择列表。 |
| 导航 | 一级当前行铺满亮灰，顶底各有一条边线；图标同框同尺寸，标签共用左边线。分组较多时用较小灰字分隔；三级设置中心的二级分类可用绿底、短白线与图标。焦点沿输入设备移动，只有激活操作才改变当前分类。 |
| 输入框 | 深灰内凹面、深轮廓、上内影、浅色值，单位可放在行标题末。给数字和中文留够宽，焦点、光标和错误状态可辨。 |
| 滚动区 | 在正文末端预留轨道，浅色方滑块置于深窄槽中。顶栏固定，导航较长时独立滚动；正文与控件和滚动条之间留白。 |
